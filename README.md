### 📂 Proyectos Destacados

Sistema avanzado para el control y administración de inventarios en consola. 
* **Foco técnico:** Limpieza y validación rigurosa de entradas de usuario (Data Cleaning) y manejo estructurado de flujos de datos.
* **Paradigma:** Desarrollado bajo un enfoque incremental, priorizando la estabilidad y la programación defensiva.

#### ✂️ [BarberShop Manager](https://github.com)
Aplicación de consola diseñada para la gestión integral de turnos y servicios en una barbería.
* **Foco técnico:** Implementación de lógica modular y persistencia de datos (JSON), garantizando una experiencia de usuario fluida y sin conflictos de horarios.

Solución de software dedicada al seguimiento y categorización de finanzas personales.
* **Foco técnico:** Automatización de cálculos financieros básicos e interfaces interactivas por línea de comandos para el análisis de reportes.
